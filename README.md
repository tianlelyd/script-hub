# script-hub
Some commonly used scripts

## maskData

脱敏数据「Json OR Yame」

```shell
node .\maskData.js -t json -f .\mrsoft.common.config.json -o .\mrsoft.common.config--.json
```

## generateStructure

生成项目文件夹结构树

```shell
node ..\script-hub\generateStructure.js ./
```
